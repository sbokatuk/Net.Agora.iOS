## What's changed

`Net.Agora.Video.iOS`, `Net.Agora.Voice.iOS` and the twelve `Net.Agora.Extensions.*.iOS` packages
advance to **4.6.2.5**. The native SDK is unchanged at AgoraRtcEngine_iOS 4.6.2; what changed is the
C# surface.

### The engine's delegate is exposed as C# events

`AgoraRtcEngineDelegate` is an all-optional protocol on a class with a single delegate slot — the
textbook case for the binding generator's event support, which this binding was not using. Every
bound callback is now an event on the engine:

```csharp
engine.DidJoinedOfUid += (_, e) => Attach(e.Uid);
engine.ConnectionChangedToState += (_, e) => Log(e.State, e.Reason);
```

Ten events on Video, nine on Voice (which has no `DidVideoMuted`). The `EventArgs` types are part of
the package's API surface.

One caveat inherited from how Apple bindings do this everywhere: **events and a hand-assigned
delegate are mutually exclusive.** Subscribing an event installs the generator's own delegate,
replacing whatever was set — including the one passed to `SharedEngine` — and assigning `Delegate`
afterwards detaches the events. Pick one style per engine instance. The `Delegate`/`WeakDelegate`
property pair is now bound too, for the subclass style; it is weak, so keep your delegate rooted.

### `new AgoraRtcEngineKit()` no longer compiles

The engine only exists through `SharedEngine`. The type previously had an implicit public
constructor, which compiled and handed back an object that was not the shared engine — a silent
runtime failure. It now carries `[DisableDefaultCtor]`. This is deliberately a source-breaking
change for code that was already broken.

### The RTM device slice is thinner

Not this track, but worth noting alongside: see `signaling-v2.2.6.2.md`.
