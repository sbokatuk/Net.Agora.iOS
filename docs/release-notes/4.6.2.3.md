## What's changed

**`Net.Agora.Signaling.iOS` debuts**, at its own version **2.2.6.1**: hand-written .NET for iOS /
.NET MAUI bindings for [`AgoraRtm_iOS` 2.2.6](https://cocoapods.org/pods/AgoraRtm_iOS) — Agora's
Signaling (RTM 2.x) SDK. Two xcframeworks (`AgoraRtmKit` + `aosl`), with the visionOS slices
Agora ships only for this SDK stripped by `build/fetch-signaling.sh` (the packages target iOS
only, and the script prunes the matching `Info.plist` entries so the manifests stay consistent
with what is on disk).

Scoped to the messaging core, like every binding in this repository is scoped to what the
cross-platform client needs: `AgoraRtmClientKit` construction, login/logout,
subscribe/unsubscribe, string publish, token renewal, and the delegate callbacks for messages,
connection state and token expiry. `AgoraRtmErrorInfo` is an `NSError` subclass and is bound as
one. Stream channels, topics, presence, storage, locks and history stay unbound until needed.

Most apps want the cross-platform client instead:
[`Net.Agora.Signaling`](https://github.com/sbokatuk/Net.Agora), which wraps this package and its
Android sibling behind one awaitable API.

**Releases now publish each package at its own version.** Signaling's 2.2.x native line is what
forces it: no single tag version can be stamped across packages anymore, so `BuildNugets.sh`
packs every package at its own pin from `Directory.Build.props` (`--suffix` for prereleases), a
tag is just the train's label, and a package whose pin did not move since the previous train is
skipped by the push rather than republished. `Net.Agora.Video.iOS` and `Net.Agora.Voice.iOS`
advance to `4.6.2.3` for that packaging change — their binding surface is identical to `4.6.2.2`.

> **Package versions are `<pod version>.<binding revision>`.** The fourth component belongs to
> this repository and advances when the bindings or packaging change while the native artifact
> stays put.

## Tests

- **Package tests** hold the Signaling package to the same guards as the RTC pair, at its own
  scale: two expected xcframeworks, a smaller payload floor, iOS device + simulator slices only
  (which is also what proves the visionOS stripping worked), manifests consistent with the
  slices shipped.
- **Simulator smoke tests** keep their Video and Voice flavours; the Signaling package is
  exercised end to end by the [façade repository](https://github.com/sbokatuk/Net.Agora)'s own
  simulator suite, which drives login/publish/subscribe against this packed payload.
