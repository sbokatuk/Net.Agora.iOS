# SHA-256 of each Agora iOS SDK release's download.agora.io zip, keyed by archive name
# (<artifact>-<version>): the Video and Voice pods share version numbers, so the version alone
# does not identify an archive.
#
# Agora publishes no checksum manifest of its own alongside the SDK download, so the hash is
# pinned here, in the repository, and the fetch scripts refuse to use an archive that does not
# match.
#
# That makes this file the trust anchor for the native code (AgoraRtcKit and its codec
# dependencies) that gets linked into consumers' apps: a substituted or truncated archive fails
# the fetch instead of being bound and published. It also makes the build reproducible, since the
# download URL can be replaced in place without the version in the URL changing.
#
# To add a version, download the archive and record its hash:
#
#   a=AgoraRtcEngine_iOS   # or AgoraAudio_iOS
#   v=4.6.2
#   curl -fsSL -o $a-$v.zip "https://download.agora.io/sdk/release/$a-$v.zip"
#   shasum -a 256 $a-$v.zip
#
# Format: <artifact>-<version> <sha256>
#
# Products built from source rather than downloaded — today the Interactive Whiteboard and
# Fastboard, which netless publishes as CocoaPods *source* pods with no binary to fetch — are
# pinned by commit instead, since there is no archive to hash:
#
#   git:<owner>/<repo>@<tag> <40-hex commit>
#
# A tag is a mutable pointer and netless has re-tagged before, so the tag is only how the clone
# finds the commit; the commit is what the build scripts verify. To add one:
#
#   git ls-remote https://github.com/netless-io/Whiteboard-iOS.git refs/tags/2.16.137
#
# An annotated tag has two lines there; the commit is the peeled one, ending in ^{}.
#
# These lines pin the products themselves. What each one pulls in through SwiftPM is pinned by the
# lockfiles in native/: see build/build-fastboard.sh and build/build-whiteboard.sh.
